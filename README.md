# Hospitality Hub Pro

Build a modern, premium SaaS web application called "ChefConnect Pro" (temporary name).

The software is an AI-powered Restaurant, Hotel, Cafe and Hospitality Staffing Platform.

Target Users:

1. Restaurant Owners

2. Employees (Chef, Helper, Waiter, Bartender, Housekeeping, Bakery Staff, Manager, Captain, Barista, Tandoor Chef, Chinese Chef, Continental Chef, South Indian Chef, Pizza Maker, Cashier, Steward etc.)

3. Admin

IMPORTANT BUSINESS RULE:

Restaurant Owners CANNOT directly contact Employees.

Employees CANNOT directly contact Owners.

All communication must go through Admin.

Owner can only click:

"Request Staff"

Employee can only click:

"Apply"

Admin receives both requests and manually connects them.

This is the biggest feature.
